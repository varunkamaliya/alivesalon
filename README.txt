ALIVE SALON UNISEX — WEBSITE CONCEPT
====================================
Open index.html in a browser to preview. Internet access is required for Google Fonts and Unsplash image URLs.

This is a polished proposal concept based on the Google Maps link resolving to Alive Salon Unisex in Mumbai (Malabar Hill area). Public information available during creation was limited, so service categories and copy are proposed rather than verified salon offerings.

Before publishing, confirm with the owner:
- Exact address, phone/WhatsApp, opening hours and booking process
- Actual service menu, prices, products/brands and team details
- Permission to use salon-owned photos, logo and customer testimonials

Files:
- index.html — page structure and copy
- style.css — responsive design and image styling
- script.js — mobile navigation interaction

Images are remote Unsplash URLs; replace with the salon's own approved imagery for the final client site.
